# Serello

O Serello é um site simples para pesquisar e guardar séries para assistir depois.

A ideia foi fazer uma página fácil de usar, com algumas séries, uma busca e uma área para salvar as favoritas.

## O que tem

- Página inicial com seis séries
- Busca pelo nome
- Página de detalhes de cada série
- Minha lista para guardar séries
- Navegação entre as páginas
- Algumas informações são buscadas na API do TVMaze
- Layout que funciona no computador e no celular

## Séries

- The Flash
- Brooklyn Nine-Nine
- The Mentalist
- Dexter
- Arrow
- Breaking Bad

## Onde usamos IA

A gente usou a IA principalmente para ajudar durante o desenvolvimento do projeto.

Ela ajudou a gente a entender melhor algumas partes do React, principalmente os componentes, o useState e o useEffect. Também usamos para tirar dúvidas sobre a API, organizar algumas partes das séries e encontrar alguns erros que apareceram enquanto a gente estava fazendo o projeto.

Além disso, usamos a IA para ajudar em alguns ajustes do visual, como as cores, a posição das imagens e o efeito quando passamos o mouse nas séries.

## Como abrir

Abra a pasta no VS Code e rode no terminal:

npm install

Depois:

npm run dev

O endereço do site vai aparecer no terminal.
