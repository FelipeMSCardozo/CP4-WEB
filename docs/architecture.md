# Como o projeto foi organizado

O projeto foi separado em partes pequenas para ficar mais fácil de entender.

## Componentes

- Cabecalho: mostra o nome do site e os links.
- CartaoSerie: mostra cada série.
- GradeSeries: organiza os cartões.

## Páginas

- PaginaInicial
- PaginaDescobrir
- PaginaSerie
- PaginaLista

## Funcionamento

O React Router troca as páginas.

O useState guarda as séries salvas e o texto da busca.

As informações principais das seis séries ficam em uma lista simples dentro do projeto. Na página da série, alguns dados também são conferidos na API do TVMaze.
