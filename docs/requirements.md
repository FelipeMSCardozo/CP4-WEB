# Requisitos do projeto

## Objetivo

Criar uma página em React para ajudar a escolher séries e guardar algumas para assistir depois.

## Problema escolhido

Às vezes a pessoa quer ver alguma série, mas não sabe qual escolher ou acaba esquecendo as que gostou.

## Solução

O Serello mostra seis séries, permite pesquisar pelo nome, abrir uma página com mais informações e montar uma lista pessoal.

## O que o usuário pode fazer

- Pesquisar pelo nome de uma série
- Abrir os detalhes de uma série
- Adicionar uma série à lista
- Remover uma série da lista

## Requisitos técnicos

- React com componentes
- Props entre componentes
- React Router com mais de uma página
- Rota dinâmica para cada série
- useState para interação
- Biblioteca de ícones
- Interface que funciona no computador e no celular
